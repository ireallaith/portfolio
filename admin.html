Content Admin

Manage Research, Articles, Experiments, and Open Source entries — every save publishes straight to your GitHub repo.

Use a fine-grained token scoped to only this one repo, with "Contents" permission set to Read and write — not a broad token with full account access. Generate one at github.com/settings/personal-access-tokens. It's saved only in this browser's local storage and sent only to api.github.com — never anywhere else. Don't use this panel on a shared or public computer.
